# Svalbard Idea Vault

A corpus of **2,669,631 arXiv papers**, each reduced to the research *idea* it
contains: the problem it defines, the intuition behind its approach, and a
statement of its proposal with all measured results removed.

```python
from datasets import load_dataset

test = load_dataset("Jerry999/SvalbardIdeaVault", split="test")
pool = load_dataset("Jerry999/SvalbardIdeaVault", split="corpus")
```

## Splits

| split | records |
|---|---:|
| `train` | 14,149 |
| `validation` | 195 |
| `test` | 272 |
| `corpus` | 2,655,015 |

`train` / `validation` / `test` are an evaluation benchmark drawn from recent
methodology papers. `corpus` is the remainder of the vault.

## Fields

| field | type | description |
|---|---|---|
| `arxiv_id` | string | arXiv identifier, unversioned (e.g. `2605.00737`) |
| `arxiv_url` | string | abs page for the paper |
| `title` | string | paper title |
| `authors` | list[string] | author names |
| `abstract` | string | arXiv abstract |
| `categories` | list[string] | arXiv subject categories |
| `date` | string | submission date, `YYYY-MM-DD` |
| `problem_definition` | string | the formal setting — inputs, outputs — and the problem being attacked |
| `intuition` | string | the core idea at analogy level, free of notation |
| `proposal_masked` | string | the paper's full proposal: thesis, novelty, method, planned evaluation, limitations — with measured results removed |
| `split` | string | `train` / `val` / `test` / `corpus` |
| `generated_at` | string | timestamp of annotation generation |

## Limitations

`problem_definition`, `intuition` and `proposal_masked` are generated by a
large language model from each paper's full text. They may be inaccurate or
incomplete, and they do not represent the views or claims of the original
authors. Cite the paper, not the annotation.
